# Kartik Chandel — Personal Portfolio Website

A hyper-modern, light-themed personal portfolio website built with **React**, **Tailwind CSS**, **Three.js**, and **Framer Motion**.

---

## 🌟 Features

- **Ultra-Clean Light Aesthetic**: Cohesive pastel ambient gradients (`#F8FAFC`), glassmorphism (`backdrop-blur`), and soft shadows.
- **Interactive 3D WebGL Element**: Three.js canvas featuring a responsive, mouse-tracking 3D geometric torus with ambient stardust particles.
- **Dynamic Typing Text FX**: Real-time rotating roles in the Hero section ("Full Stack Web Developer", "QA Automation Engineer", etc.).
- **Ambient Cursor Spotlight**: Subtle cursor follower that illuminates the background with gentle pastel glows.
- **Projects Showcase & Categorization**:
  - **PulseFit**: Mobile fitness & health tracking application (Flutter APK releases).
  - **FieldWin (Sales CRM App)**: Private enterprise field sales intelligence & geofencing platform showcase (under NDA).
  - **Mahajanride.com**: Live production cab & travel booking web platform.
  - **KIRA**: Personal Jarvis AI Assistant (Python, FastAPI, Docker, Android).
  - **Auto-QA**: Playwright E2E automation & regression test framework.
- **Direct Communication Badges**: One-click redirection to WhatsApp, Email, Phone Call, LinkedIn, GitHub, and Instagram.
- **Celebratory Contact Form**: Interactive inquiry form with celebration confetti and direct dispatch via WhatsApp or Email.

---

## 🚀 Tech Stack

- **Frontend**: React 19, JavaScript (ES6+), HTML5, CSS3
- **Styling**: Tailwind CSS, PostCSS, Autoprefixer
- **3D & Motion**: Three.js (WebGL), Framer Motion, Canvas Confetti
- **Icons**: Lucide React & Custom Brand SVGs
- **Build Tool**: Vite

---

## 🛠️ Local Development

1. **Install Dependencies**:
   ```bash
   npm install --legacy-peer-deps
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

3. **Build for Production**:
   ```bash
   npm run build
   ```
